1. EXECUTIVE SUMMARY & COMPLIANCE ASSURANCE
================================================================================

ai-media-editor is engineered under strict architectural and governance invariants:
100% Local-First, Zero-Egress by default, unprivileged user-mode execution (RunAsInvoker),
and pure offline operation. The media preparation, local speech-to-text routing
(faster-whisper, WhisperX), Scribe JSON schema generation, frame extraction, pause
detection, and procedural music synthesis operate entirely within local process and
filesystem boundaries without unsolicited network communication or telemetry.

Most runtime dependencies are permissively licensed (MIT, MIT-0, MIT-CMU, ISC, 0BSD,
Zlib, CC0-1.0, Apache-2.0, BSD, PSF-2.0). Weak-copyleft components (used unmodified as
separate packages): certifi (MPL-2.0), tqdm (MPL-2.0 AND MIT), soxr (LGPL-2.1-or-later)
and the FFmpeg shared libraries bundled in the PyAV (av) wheels (LGPL-3.0-or-later on
macOS arm64). No package declares GPL, AGPL or SSPL terms. Details: section 3a.

3. COPYLEFT BOUNDARIES & RUNASINVOKER CERTIFICATION
================================================================================

1. Copyleft Boundaries & Dynamic Linking:
   FFmpeg CLI: ai-media-editor itself calls FFmpeg only as an external program across
   subprocess boundaries (subprocess.run / subprocess.Popen) using standard streams.
   Users can swap, patch, or upgrade the FFmpeg binary independently.
   FFmpeg libraries via PyAV: The locked runtime contains PyAV (av, BSD-3-Clause), which
   faster-whisper uses for audio decoding. Its wheels bundle FFmpeg shared libraries
   that are loaded dynamically in-process. On macOS arm64 (av 18.1.0) FFmpeg reports
   "LGPL version 3 or later" (--enable-version3, no --enable-gpl). The wheel also
   bundles further codec libraries (e.g. dav1d, opus, mp3lame, opencore-amr, SVT-AV1)
   whose individual licenses were not audited separately; the Windows wheel was not
   inspected.
   Weak-copyleft Python packages: certifi (MPL-2.0), tqdm (MPL-2.0 AND MIT) and soxr
   (LGPL-2.1-or-later) are installed by the user from PyPI as separate, unmodified
   packages; ai-media-editor neither vendors nor modifies them.

2. Unprivileged Execution (RunAsInvoker):
   ai-media-editor requires no administrative privileges, no daemon services, no root
   credentials, and no kernel-level device drivers. It operates entirely in unprivileged
   user space under standard user profiles.

3. Zero-Egress Perimeter:
   By default, no network traffic is emitted by ai-media-editor. All transcription models,
   waveform computations, and frame contact sheets are processed on local compute.
   Controlled remote compute via SSH is strictly opt-in and governed by isolated job
   directories and mandatory remote cleanup.
