# Third-Party Licenses / Drittanbieter-Lizenzen

This document lists the third-party open-source software and tools integrated or utilized by `ai-media-editor`.

| Component / Dependency | License | Project / Upstream URL | Description |
|------------------------|---------|------------------------|-------------|
| **video-use** | MIT | https://github.com/browser-use/video-use | Word-level transcript-based video cutting engine |
| **Hyperframes** | Apache-2.0 | https://github.com/heygen-com/hyperframes | HTML/CSS/JavaScript to MP4 motion graphics renderer |
| **faster-whisper** | MIT | https://github.com/SYSTRAN/faster-whisper | Fast local speech-to-text engine based on CTranslate2 |
| **WhisperX** | BSD-2-Clause | https://github.com/m-bain/whisperX | Word-level forced alignment and acoustic diarization |
